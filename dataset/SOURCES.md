# Dataset sources

SVG originals live in `dataset/svg/`. `dataset.py` rasterises them into
`samples/bench/` and records each original's node count as ground truth,
so the benchmark can ask *how close are we to what the designer actually
drew* rather than only comparing pixels.

**Only add assets whose licence permits redistribution.** Record every
one below with its licence and URL. Anything unlicensed or unclear stays
out of git — add it to `.gitignore` and keep it local.

## Where to get more

Each of these publishes SVG, which is what makes ground truth possible.
Verify the licence on the official page before adding — aggregator blogs
get this wrong.

| Source | Licence | Good for |

## Coverage to aim for

The fixtures should span the axes the tracer is sensitive to, not just
look varied:

- [x] Flat illustration with organic curves — `10-flat-scene`
- [x] Geometric mark with a compound path — `11-brand-mark`
- [x] Thin strokes of varying weight — `02-outlined-icon`
- [x] Continuous tone — `05-smooth-gradient`
- [x] Noise — `06-grain-texture`
- [ ] **Flat illustration with abutting fills and no outlines** — exposes
      the shared-edge gap, the one failure reasoned about but never measured
- [ ] Stroke-based icon set at 1–2px weight
- [ ] Lettering or a wordmark — do letterforms survive
- [ ] UI screenshot — flat rects plus small text
- [ ] Engraving or halftone — fine parallel lines

## Adding assets

```bash
# drop .svg files into dataset/svg/, then
python3 dataset.py --width 480
python3 compare.py --input samples/bench --out compare-out
```

Raster-only assets (photos, scans) go straight into `samples/bench/` —
`bench.py` and `compare.py` pick up anything there, they just won't have
ground truth.
